## Twitter Sentiment Analysis on Apple and Google Products

## Project Overview
This project builds an NLP model to classify tweets about 
Apple and Google products as positive, negative, or neutral.

## Business Problem
Companies receive thousands of tweets daily. This model 
automates sentiment classification to help businesses 
monitor customer feedback efficiently.

## Dataset
- Source: CrowdFlower via data.world
- 9,070 tweets with sentiment labels

## Models Used
- Multinomial Naive Bayes
- Logistic Regression (best performer - 69.3% accuracy)
- Random Forest Classifier

## Technologies Used
- Python, pandas, numpy
- NLTK, scikit-learn
- Matplotlib, seaborn
